# 교차로 깊숙한 우회전 대기 위치

근거는 일본 국토교통성 사가국도사무소가 2020년 3월 작성한 [사가현 도로교통환경 안전추진 연락회의 자료](https://www.qsr.mlit.go.jp/sakoku/site_files/file/pdf/trafficsafe/r1/7r1_zikotaisaku.pdf)다. PDF의 5–7쪽을 사진과 도면까지 직접 확인했다.

## 확인한 실제 사례

- 장소: 국도 202호, 가라쓰시 **浜玉中前 교차로**.
- PDF 5쪽: 넓고 어긋난 교차로의 도면과 현장 사진. 진입 후 회전할 때까지의 이동 구간이 길다.
- PDF 6쪽: 우회전 유도선의 대기 위치를 기준으로 5m 구간을 나누어 정차 위치를 조사했다. 대기 위치보다 한참 뒤에서 기다리는 차량의 실제 사진도 실려 있다.
- PDF 7쪽: 진입부의 적신호와 교차로 내부 우회전 대기를 별도로 다룬다. 안쪽 대기 위치가 적신호 진입을 허용하는 별도 정지선이라는 근거가 아니다.

## 앱에 반영한 범위

`turn-01`부터 `turn-11`까지는 이 사례에서 확인한 **넓은 교차로, 어긋난 연결 도로, 긴 우회전 진입 구간, 안쪽 대기 유도 표시**를 학습용으로 다시 구성했다. 현재 현장의 실측 지도나 최신 신호 운영을 재현한 것은 아니다. 문항의 신호·차량·보행자 상태는 각 판단 상황에 맞게 별도로 배치했다.

- A: 교차로 진입 전, 신호에 따라 멈추는 정지선.
- B: 교차로에 들어온 뒤 우회전을 기다리는 내부 안내 위치.
- A와 B 사이를 자동차 다섯 대 길이 이상으로 그려, 기존의 조금 어긋난 두 정지선과 시각적으로 구별했다. 그림의 길이 비율은 학습용이며 현장의 실제 거리 수치가 아니다.
- 신호가 초록인 진입 전, 적색인 진입 전, 직진 화살표만 켜진 진입 전, 이미 진입했지만 너무 이른 위치, B에서 대기 중인 상태를 각각 다른 그림으로 만들었다.
- B를 별도의 신호 정지선이라고 설명하지 않는다. 대기 표시의 모양만으로 진입 가능 여부를 판단하게 하지 않는다.

법규 판단은 [NPA 교통 교칙](https://www.npa.go.jp/bureau/traffic/20241113kyousoku.pdf)과 [신호 안내](https://www.npa.go.jp/english/bureau/traffic/traffic-light_english.pdf)를 함께 적용한다. 일반 초록불에 안전을 확인해 우회전 진입할 수 있고, 맞은편 직진·좌회전 차량에 양보해야 한다. 적신호에 진행 방향을 허용하는 화살표가 없으면 A를 넘지 않는다.

## 황색 중앙선 기본 문제

`entry-01`에는 황색 실선 중앙선을 건너 오른쪽 시설로 진입하는 기본 허용 상황이 이미 있다. 이제 이 문항 자체를 매 시험에 반드시 포함한다. 황색 중앙선과 같은 방향 차로의 황색 경계선을 구분하고, 횡단금지 표지·접근 차량·인도가 추가되는 상황은 별도 문제로 다룬다.
