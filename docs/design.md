# 선데이 드라이브

한국에서 운전하던 사람이 일본 여행 전에 그림을 보고 판단하는 연습. 암기 목록보다 상황 이해가 먼저다.

## 시각 방향

참고: https://www.jungle.co.kr/image/fd13918c415f8b819a76f042

아이소메트릭 도시 안내도의 작은 건물, 나무, 도로를 앱 심볼로 만든다. 문제 그림은 도로 구조와 신호를 정확히 읽는 것을 우선하고, 주변 건물에 입체감을 준다. 큰 그림 한 장과 두 선택지가 중심이다.

- 바탕: mist `#edf3ee`
- 글자: pine `#173e38`
- 강조: evergreen `#347b69`
- 내 차: persimmon `#e67855`
- 주변 차량과 지붕: sky `#bad6df`
- 도로와 패널: chalk `#fafcf8`
- 한글: 시스템 한글 산세리프, 본문 18–20px, 질문 28–40px. 로고는 Georgia 이탤릭으로 여행의 여유를 표현한다.

## 화면 구성

홈은 가운데 큰 일본 도로 심볼·워드마크와 시작 버튼만 둔다. 기능 설명이나 카드 목록은 추가하지 않는다.

```
홈                 문제                      결과
  일본 도로 심볼    홈             01 / 25    운전 스탬프
  Sunday drive     [큰 상황 그림 + 내비]       점수 · 통과 여부
  [시작하기]       짧은 질문                  [틀린 문제 복습]
                   [행동 A] [행동 B]          [다시 시험 보기]
                   답 확인 후 해설·다음
```

모바일에서는 선택지를 세로로 쌓고, 내비게이션 패널은 그림 안에서 명확하게 구분한다. 진행 표시·점수만 숫자로 강조한다. 법규 출처는 해설에서 열 수 있게 한다.

## 동작

74개 문제 중 범주를 고르게 섞어 25개를 출제한다. 한 문제는 4점, 90점 이상인 23개 정답(92점)부터 통과다. 보기 위치도 섞되 시험 도중에는 고정한다. 답을 고르면 정답과 짧은 이유를 보여준다. 오답은 같은 그림으로 다시 풀고, 재시험은 새 문제 세트로 시작한다. 새로고침해도 시험과 최근 결과를 복구한다. 기존 20문항 시험은 문항 수와 점수를 그대로 유지하며, 배점과 통과 안내도 해당 시험의 실제 문항 수로 계산한다.

일반적인 카드형 대시보드 대신 한 장의 운전 연습장처럼 구성한다. 홈에 설명을 늘리지 않고 그림·문장·버튼의 크기에 집중한다.
