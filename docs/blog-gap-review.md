# 참고 블로그와 문제 은행 비교

검토일: 2026-11-05. [사용자가 지정한 글](https://m.blog.naver.com/charlestoney/223373789131)은 2024-03-05 게시된 일본 렌터카 운전 안내다. 별도 Chrome 창에서 본문 전체를 읽고 지정방향·일방통행, 주정차, 일시정지·보행자 전용 표지 그림을 직접 확인했다. 글은 빠진 상황을 찾는 참고 자료로 사용하고, 정답은 아래 공식 자료로 다시 확인했다. 사진이나 문장을 복제하지 않고 독립적인 상황 그림과 문항을 작성했다.

## 기존에 다루던 내용

- 적신호와 녹색 방향 화살표 조합: `signal-01`~`signal-12` 및 깊은 우회전 상황.
- 황색 중앙선과 오른쪽 시설 진입, 횡단금지: `entry-01`~`entry-03`. 당시 함께 검토했던 왼쪽 시설 진입 문항 `entry-04`는 이후 출제에서 제외하고 양보 차량 옆 이륜차를 판단하는 `entry-13`으로 교체했다.
- 유턴 금지 표지와 일반 우회전 시설 진입의 차이: `entry-08`.
- 왼쪽 통행과 내 차 식별: 모든 도로 그림에 반영.

## 공식 근거와 보완한 조건

- [도로표지령](https://laws.e-gov.go.jp/law/335M50004002003): 지정방향 외 진행 금지, 일방통행, 보행자 전용, 주차·주정차 금지와 시간 보조표지. 원형 직진 화살표를 일방통행으로 설명하지 않는다.
- [NPA 안전운전 안내](https://www.npa.go.jp/bureau/traffic/anzen/poster/r8_leaflet_japan_anzenunten_jp.pdf): 실제 표지 형태를 확인했다. 신호 없는 그림에는 신호등을 추가하지 않는다.
- [JAF Mate 유턴 해설](https://jafmate.jp/safety/traffic_rules_quiz_20230524.html), [도로교통법](https://laws.e-gov.go.jp/law/335AC0000000105) 제25조의2: 오른쪽 녹색 화살표는 일반 승용차의 유턴도 허용하지만 유턴 금지 표지·표시와 정상 교통 방해 여부를 별도로 판단한다. 어디서든 무조건 유턴할 수 있다는 문구는 사용하지 않는다.
- [가나가와현 경찰](https://www.police.pref.kanagawa.jp/kotsu/kotsu_torishimari/mesf2002.html): 정지선 직전 완전 정지 후 시야가 확보되는 곳까지 서행, 필요하면 재정지. B를 두 번째 법정 정지선처럼 그리지 않는다.
- [오사카 경찰 주차 정의](https://www.police.pref.osaka.lg.jp/kotsu/tyusya/21011.html): 사람을 기다리는 주차와 실제 승하차 정차를 구분한다. 5분 미만이면 모두 허용된다는 오해를 방지한다.
- [오사카 경찰 금지 장소](https://www.police.pref.osaka.lg.jp/kotsu/tyusya/jogai/5980.html): 횡단보도 가장자리 앞뒤 5m. 시간 규제 종료가 모든 장소의 주차 허가라는 뜻은 아니다.
- [국민생활센터 렌터카 안내](https://www.kokusen.go.jp/news/data/n-20250328_1.html): 작은 흠집도 현장에서 경찰과 대여업체에 연락. [토요타 사고 안내](https://rent.toyota.co.jp/static/guide/irregular/)도 확인했다. 보험·면책 가입이 무조건 비용 0원이라는 주장은 사용하지 않는다.
- [홋카이도 사고 대응](https://www.pref.hokkaido.lg.jp/ks/cak/kat/safety-drive/accident.html): 추가 사고 방지, 구호, 119·110, 렌터카 회사 연락.
- [토요타 출발 전 확인](https://toyota.jp/after_service/tenken/daily/step3/detail/): 방향지시등과 와이퍼 작동 확인. 레버의 위·아래 방향이나 좌우 배치를 모든 차종에 일반화하지 않고 그림 속 기호로 식별한다.

## 출제와 저장 호환

총 74문항이다. 후속 요청으로 새 시험은 25문항·문항당 4점으로 확장했다. 90점 이상 기준을 유지하므로 23개 정답(92점)부터 통과한다. 범주별 출제 수는 신호 5, 우회전 4, 시설 진입 4, 차로 3, 건널목 3, 우선순위 3, 정차·돌발 상황 3이다. 기존 필수 주제는 유지하며, 건널목을 제어하지 않는 별도 교차로 신호는 ‘건널목용 차량 신호 없음’ 묶음에 포함한다. 저장된 20문항 시험은 원래 문항 수와 점수로 이어서 풀거나 복습할 수 있다.

기존 문항 ID와 정답 인덱스는 바꾸지 않는다. `2026-11-04.4`·`2026-11-04.5` 저장 시험과 복습을 복구하고 새 시험부터 확장된 출제 비율을 적용한다.
