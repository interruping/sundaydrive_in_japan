# Sunday Drive · 선데이 드라이브

한국 운전자를 위한 일본 운전 상황 퀴즈. 모든 문제에 그림이 있고, 두 행동 중 하나를 고릅니다.

## 실행

Node.js 22 이상. 앱 실행에 외부 패키지 설치나 빌드가 필요하지 않습니다.

```sh
npm run dev
```

http://localhost:4173 에서 열 수 있습니다. `PORT=3000 npm run dev`로 포트를 바꿀 수 있습니다.

## 구성

- `dist/`: 바로 호스팅할 수 있는 HTML, CSS, JavaScript, SVG
- `scripts/`: 정적 개발 서버와 문법 검사
- `tests/`: 문제 은행, 출제·채점·저장 검증
- `docs/`: 디자인 방향과 교통법규 출처

## 검증

```sh
npm run check
npm test
```

60개 중 20문제를 출제하며 90점 이상이면 통과합니다. 각 문제의 해설에서 공식 자료를 확인할 수 있습니다. 문제와 채점은 브라우저에서 실행되고 진행 상황은 사용 중인 브라우저에 저장됩니다.
